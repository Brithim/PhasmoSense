# PhasmoSense — Automated Phasmophobia Companion & Overlay

**PhasmoSense** is a 100% external, anti-cheat-safe Windows desktop companion and in-game overlay for *Phasmophobia*. It combines **real-time Screen Capture / Computer Vision**, **WASAPI Loopback Audio DSP**, and a **24-Ghost Behavioral & Evidence Deduction Engine**.

## Quick Start

Double-click **start-phasmosense.bat** (or run it from a terminal).

> **Tip:** Set Phasmophobia's Display Mode to **Fullscreen Windowed (Borderless)** so the transparent overlay renders directly on top of the game.

## Default Global Hotkeys (All Rebindable in UI)

| Hotkey | Action |
| :--- | :--- |
| **`Alt + Q`** | Swap between **Compact Click-Through Mini-HUD** and **Discord-Style Full Interactive Overlay** |
| **`Alt + Z`** | Undo the most recent auto-applied CV/Audio detection |
| **`Alt + T`** | Start / Stop the 180s Smudge Incense Timer (`60s` Demon / `90s` Standard / `180s` Spirit markers) |
| **`Alt + B`** | Manual Tap-Tempo Footstep Speed backup |
| **`Alt + R`** | Reset Match / Clear all evidence and timers |
