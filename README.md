# PhasmoSense — Automated Phasmophobia Companion & Overlay

[![Latest Release](https://img.shields.io/github/v/release/Brithim/PhasmoSense?label=Download%20Latest%20Setup%20.exe&style=for-the-badge&color=06b6d4)](https://github.com/Brithim/PhasmoSense/releases/latest)

**PhasmoSense** is a 100% external, anti-cheat-safe Windows desktop companion and in-game overlay for *Phasmophobia*. It combines **real-time Screen Capture / Computer Vision**, **WASAPI Loopback Audio DSP**, and a **24-Ghost Behavioral & Evidence Deduction Engine**.

---

## 🚀 Quick Download & Installation

1. Head to the **[Latest Release](https://github.com/Brithim/PhasmoSense/releases/latest)** and download **`PhasmoSense-Setup.exe`**.
2. Run the installer (installs directly to your AppData, **no administrator privileges required**).
3. In *Phasmophobia*, set your Display Mode to **Fullscreen Windowed (Borderless)**.
4. Launch **PhasmoSense** from your Desktop or Start Menu shortcut.

*Self-contained: No Python, Node.js, or Git required on your PC. PhasmoSense automatically checks for and applies delta updates on startup.*
